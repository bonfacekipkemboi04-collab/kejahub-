# 🏠 Keja Hub — Project Folder

## Files in this folder:

| File | Purpose |
|------|---------|
| index.html | Main public website (tenants + landlords) |
| admin.html | Admin control panel |
| SETUP-GUIDE.html | Full setup instructions |
| firebase.json | Firebase hosting config |
| .firebaserc | Links folder to your keja-hub project |
| firestore.rules | Database security rules |
| netlify.toml | Netlify hosting config |

---

## 🚀 To deploy on Netlify (Easiest — no terminal needed):

1. Go to https://netlify.com → Sign up free
2. Drag this ENTIRE folder into the Netlify deploy box
3. Your site is live in 30 seconds!

---

## 🔥 To deploy on Firebase Hosting:

Open terminal inside this folder and run:

  firebase login
  firebase deploy

Your site will be live at: https://keja-hub.web.app
