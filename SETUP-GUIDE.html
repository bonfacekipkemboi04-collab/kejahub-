🚀 Complete Setup Guide

Follow these steps to go from demo to a fully live, real-time, M-Pesa enabled platform

Overview

⚡ What You'll Set Up

  • Firebase — Free database, login system, and hosting FREE
  • Firebase Auth — Secure landlord + admin login FREE
  • Firestore — Real-time database for listings, enquiries, users FREE
  • M-Pesa Daraja API — Accept payments via STK push SAFARICOM
  • Backend Proxy — Small server for M-Pesa API calls (Render.com free tier) FREE
⏱ Estimated setup time: 2–3 hours following this guide step by step.

Step 2

🗄️ Set Up Firestore Database

  1. In Firebase Console → left menu → Firestore Database
  2. Click "Create database"
  3. Choose "Start in test mode" (you'll secure it in Step 4) → Next
  4. Select region: europe-west1 (closest to Kenya) → Enable

Collections to create (they auto-create when data is added):

  • listings — property listings
  • users — landlord accounts
  • enquiries — tenant enquiries
  • payments — M-Pesa payment records
  • stats — platform counters
✅ Firestore auto-creates collections when your first document is saved. No manual setup needed.
Step 3

🔐 Set Up Firebase Authentication

  1. Firebase Console → left menu → Authentication
  2. Click "Get started"
  3. Click "Email/Password" → Enable it → Save

Create your Admin Account:

  1. Go to Authentication → Users tab → "Add user"
  2. Email: admin@kejahub.co.ke (or your own email)
  3. Password: choose a strong password (min 8 chars, uppercase + number)
  4. Click "Add user"

Step 4

🛡️ Firestore Security Rules

Go to Firestore → Rules tab → replace everything with this:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // LISTINGS: Anyone can read. Only logged-in users can create.
    // Only the owner or admin can update/delete.
    match /listings/{id} {
      allow read: if true;
      allow create: if request.auth != null;
      allow update, delete: if request.auth != null &&
        (request.auth.uid == resource.data.landlordId ||
         request.auth.token.email == "admin@kejahub.co.ke");
    }

    // USERS: Users can read/write their own doc. Admin reads all.
    match /users/{userId} {
      allow read, write: if request.auth != null &&
        (request.auth.uid == userId ||
         request.auth.token.email == "admin@kejahub.co.ke");
    }

    // ENQUIRIES: Anyone can create. Only admin reads all.
    match /enquiries/{id} {
      allow create: if true;
      allow read, update, delete: if request.auth != null &&
        request.auth.token.email == "admin@kejahub.co.ke";
    }

    // PAYMENTS: Only admin can read/write.
    match /payments/{id} {
      allow read, write: if request.auth != null &&
        request.auth.token.email == "admin@kejahub.co.ke";
    }

    // STATS: Anyone reads. Only server writes (via admin SDK).
    match /stats/{id} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}

Click Publish after pasting.

Step 6

⚙️ Deploy the M-Pesa Backend

M-Pesa API credentials must never be exposed in your HTML. You need a small backend server. Deploy for free on Render.com.

Create this Node.js server (save as server.js):

const express = require('express');
const axios = require('axios');
const cors = require('cors');
require('dotenv').config();

const app = express();
app.use(express.json());
app.use(cors({ origin: '*' })); // Lock to your domain in production

const {
  MPESA_CONSUMER_KEY,
  MPESA_CONSUMER_SECRET,
  MPESA_PASSKEY,
  MPESA_PAYBILL,
  MPESA_CALLBACK_URL,
  FIREBASE_ADMIN_KEY  // optional: for writing payment records
} = process.env;

// Get OAuth token from Safaricom
async function getToken() {
  const auth = Buffer.from(
    `${MPESA_CONSUMER_KEY}:${MPESA_CONSUMER_SECRET}`
  ).toString('base64');
  const res = await axios.get(
    'https://sandbox.safaricom.co.ke/oauth/v1/generate?grant_type=client_credentials',
    { headers: { Authorization: `Basic ${auth}` } }
  );
  return res.data.access_token;
}

// STK Push endpoint — called by your frontend
app.post('/api/mpesa/stk', async (req, res) => {
  const { phone, amount, accountRef } = req.body;
  if (!phone || !amount) return res.status(400).json({ error: 'Missing phone or amount' });

  try {
    const token = await getToken();
    const timestamp = new Date().toISOString()
      .replace(/[-T:.Z]/g, '').substring(0, 14);
    const password = Buffer.from(
      `${MPESA_PAYBILL}${MPESA_PASSKEY}${timestamp}`
    ).toString('base64');

    const payload = {
      BusinessShortCode: MPESA_PAYBILL,
      Password: password,
      Timestamp: timestamp,
      TransactionType: 'CustomerPayBillOnline',
      Amount: amount,
      PartyA: phone,           // Customer phone e.g. 254712345678
      PartyB: MPESA_PAYBILL,
      PhoneNumber: phone,
      CallBackURL: MPESA_CALLBACK_URL,
      AccountReference: accountRef || 'KESTATES',
      TransactionDesc: 'Keja Hub Listing Fee'
    };

    const response = await axios.post(
      'https://sandbox.safaricom.co.ke/mpesa/stkpush/v1/processrequest',
      payload,
      { headers: { Authorization: `Bearer ${token}` } }
    );

    res.json(response.data);
  } catch (err) {
    console.error('STK Push error:', err.response?.data || err.message);
    res.status(500).json({ error: 'M-Pesa request failed', detail: err.message });
  }
});

// Callback — Safaricom calls this after user pays
app.post('/api/mpesa/callback', async (req, res) => {
  const body = req.body?.Body?.stkCallback;
  if (body?.ResultCode === 0) {
    // Payment successful
    const items = body.CallbackMetadata?.Item || [];
    const get = (name) => items.find(i => i.Name === name)?.Value;
    const paymentData = {
      mpesaRef: get('MpesaReceiptNumber'),
      amount: get('Amount'),
      phone: get('PhoneNumber'),
      paidAt: new Date().toISOString(),
      status: 'paid'
    };
    console.log('✅ Payment received:', paymentData);
    // TODO: Write to Firestore payments collection via Firebase Admin SDK
  } else {
    console.log('❌ Payment failed:', body?.ResultDesc);
  }
  res.json({ ResultCode: 0, ResultDesc: 'Success' });
});

app.listen(process.env.PORT || 3000, () =>
  console.log('🚀 Keja Hub backend running')
);

Step 7

🌐 Host Your Website

Option A — Firebase Hosting (Recommended, Free):

  1. Install Firebase CLI: npm install -g firebase-tools
  2. Login: firebase login
  3. In your project folder: firebase init hosting
  4. Select your project → public folder: . (dot) → single page: No
  5. Deploy: firebase deploy
  6. Your site will be live at https://keja-hub.web.app

Option B — Netlify (Drag and drop, Free):

  1. Go to netlify.com → Sign up free
  2. Drag your keja-hub folder into the deploy area
  3. Done — live in 30 seconds at a random URL
  4. Add a custom domain later (e.g. kejahub.co.ke)

Custom Domain (.co.ke):

  • Register at KENIC.or.ke — approx KES 1,000/year
  • Or use Truehost.co.ke — KES 800/year
  • Point your domain DNS to Netlify or Firebase (they give you the CNAME records)
